说明：Descriptor m_IntValue 4294967296 = 2^32 = SpellDescriptor.Sleep；
精灵同时具有 BuffDescriptorImmunity（挡带睡眠描述符上下文的增益）与

## 2. BuffDescriptorImmunity（反编译原文，关键部分）
  private bool IsImmune(MechanicsContext context)
  {
      ...
      bool num = Descriptor.HasAnyFlag(context.SpellDescriptor);
      ...
      return num && flag2 && flag3;
  }
  public void OnEventAboutToTrigger(RuleCanApplyBuff evt)
  {
      if (IsImmune(evt.Context)) evt.Immunity = true;
  }
说明：按“上下文的法术描述符”判定。醉梦法术带 Sleep 描述符时，同一法术上下文施加的
睡眠与恍惚增益都会被睡眠描述符免疫挡掉——“失败分支同时挂睡眠+恍惚”对描述符免疫者无效。
（条件免疫 AddConditionImmunity(Sleeping) 只挡睡眠本身，恍惚本来就照常生效。）

## 3. SpellImmunityToSpellDescriptor（反编译原文）
  protected override void OnTurnOn()
  {
      base.Data.AppliedId = base.Owner.Ensure<UnitPartSpellResistance>().AddImmunity(
          SpellImmunityType.SpellDescriptor, AlignmentComponent.None, null, Descriptor, CasterIgnoreImmunityFact);
  }
说明：向 UnitPartSpellResistance 登记整法术描述符免疫（IsImmune 按上下文判定）。

## 4. ContextActionApplyBuff.IgnoreParentContext（反编译原文，关键部分）
  TimeSpan? duration = CalculateDuration(mechanicsContext);
  MechanicsContext parentContext = (IgnoreParentContext ? null : mechanicsContext);
  Buff buff = buffTarget.Descriptor.AddBuff(Buff, parentContext, duration);
说明：IgnoreParentContext=true 时新增强益不再继承法术上下文（含睡眠描述符），
BuffDescriptorImmunity 的上下文判定不再命中，恍惚照常挂上；沉眠仍走正常上下文，照常被挡。
原版 11 处 IgnoreParentContext=true 先例（ClawFlayingCriticalBuff、ShieldBlockBuff 等），机制安全。

## 5. 本 mod 做法（SpellsSetup DrunkenDream）
失败分支：ApplyBuff(沉眠，1 轮/级，正常上下文）+
ApplyBuff(原版 Daze，1 轮，ignoreParentContext: true）。
睡眠免疫者：沉眠被挡，恍惚照常生效 1 轮；受伤醒来再挂恍惚的 Wake 机制不变。
