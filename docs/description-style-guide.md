# 描述规范：游戏文本的"内在逻辑"

> 目的：本 mod 的描述文字**不专业、不统一**（27/67 条手写了状态栏、0 处术语链接、混入实现细节与作者署名）。
> 本文从**游戏官方文案**里反推它真正的写法，作为本 mod 全部描述（法术 / 能力 / 特性）的统一规范。
>
> 证据来源：`Wrath_Data/StreamingAssets/Localization/zhCN.json`（官方中文，21 MB，按 GUID 索引）
> + `blueprints.zip`（官方蓝图，取各文本字段指向的 GUID）。抽样：火球术 / 祝福 / 加速术 / 魔法飞弹 /
> 石肤术 / 镜影术 / 解离术 / 死亡一指 / 恐惧术 + 圣疗 / 狂暴 / 破邪斩 / 引导能量 / 偷袭 / 神恩 / 闪避。

---

## 0. 一句话结论

> **官方描述 = 头区（UI 用蓝图字段自动生成）+ 正文（只写效果）+ 术语用 `{g|…}` 链接到百科。**
> 正文里**不写**学派 / 施法时间 / 距离 / 目标 / 持续时间 / 豁免 / 法术抗力 —— 那些是头区的事。

## 1. 内在逻辑：一条文本拆成三层

游戏渲染一个法术/能力时用的是 `Kingmaker.UI.MVVM._VM.Tooltip.Templates.TooltipTemplateAbility`
（反编译确认），它把文本拆成三层：

### 1.1 头区 —— **由蓝图字段自动生成，正文不重复**

| 头区行 | 数据来源（蓝图字段） | 我们代码里对应 |
|---|---|---|
| 类型 / 环级 | `Type` / `SpellLevel` | `SetType(AbilityType.Spell)` + 法术书环级 |
| 学派 | `SpellSchool` | `SpellComponent.School` |
| 描述符 | `SpellDescriptorComponent` | 同左（如"影响心灵""寒冷"） |
| 施法时间 | `ActionType` + `IsFullRoundAction` | `SetActionType` / `SetIsFullRoundAction` |
| 距离 / 目标 | `Range` + `CanTarget*` + `AoERadius/AoETargets` | `SetRange` / `SetCustomRange` / `AddAbilityAoERadius` |
| 持续时间 | **`LocalizedDuration`** | `SetLocalizedDuration("<本地化键>")` |
| 豁免 | **`LocalizedSavingThrow`** | `SetLocalizedSavingThrow(SavingThrow.X)` |
| 法术抗力 | `SpellResistance` | `SetSpellResistance(bool)` |

**结论**：`Generate` 出来的是完整状态栏。所以正文写"学派：预言；距离：60 尺；持续：1 轮；豁免：无。"
= **和头区重复**（而且头区永远是最新的，正文会过期 —— 我们刚踩过这个坑）。
⇒ **正文里删掉全部状态栏文字。**

### 1.2 正文 —— **只写"效果"，一段讲一件事**

官方火球术（**正文全文**，一个字的状态栏都没有）：

> 随着低沉的声响炸裂，火球术制造一次灼热的炎爆，对{g|Encyclopedia:Spell}法术{/g}范围内所有生物造成每{g|Encyclopedia:Caster_Level}施法者等级{/g}{g|Encyclopedia:Dice}1d6{/g}点{g|Encyclopedia:Energy_Damage}火焰伤害{/g}（最高10d6点）。成功的{g|Encyclopedia:Saving_Throw}反射豁免{/g}将使此伤害减半。

拆开看，它的**叙述顺序是固定的**：

1. **画面/总述一句**（"随着低沉的声响炸裂…制造一次灼热的炎爆"）—— 可省略，但官方几乎都有一句。
2. **主效果 + 数值**（每施法者等级 1d6 火焰，最高 10d6）。
3. **分支**（"成功的反射豁免将使此伤害减半"）—— 用**条件从句**，不写"豁免失败：…；豁免成功：…"。
4. **例外 / 限制**（多段时另起一段，如加速术的"多个加速术不叠加"、镜影术的"若你隐形则此法术无效"）。

再看规则味浓的（解离术、镜影术、加速术）：都是**先给总效果，再逐条展开可选情形，最后写例外**，
**每段只讲一件事**，段落之间用换行（官方字符串里用 `{n}` 或真实换行）。

### 1.3 短描述 —— **官方普遍留空**

火球术 / 祝福 / 魔法飞弹 / 石肤术的 `m_DescriptionShort` **都是空**，游戏回退到长描述。
⇒ 我们**不需要**额外写短描述，把长描述写清楚即可。

## 2. 标记语言：唯一的"格式"手段

游戏文本**不认 Markdown**（`**粗体**`、`- 列表` 都会原样显示）。官方只用这几类标记：

### 2.1 术语链接 `{g|键}显示文字{/g}` —— 最高频、最"专业"的标志

全库 **32963 处** `{g|Encyclopedia:…}`、**1542 处** `{g|Spells…}`、**1291 处** `{g|Condition…}`。
玩家点它能在游戏内百科里看到规则。**我们一处都没用**（0 处），这是"看着不专业"的最大来源。

写法（**链接键固定，显示文字可变**）：

```
{g|Encyclopedia:Saving_Throw}反射豁免{/g}          → 链接到"豁免检定"词条，显示"反射豁免"
{g|Encyclopedia:Dice}1d6{/g}                      → 骰子
{g|Encyclopedia:Bonus}加值{/g}                     → 加值（是否带类型看正文）
{g|ConditionStaggered}恍惚{/g}                     → 状态"恍惚"
{g|SpellsHaste}加速术{/g}                          → 指向具体法术
```

**常用 `Encyclopedia:` 键 ←→ 中文词条**（从官方取样）：

| 键 | 官方中文 | 键 | 官方中文 |
|---|---|---|---|
| `Saving_Throw` | 豁免检定 | `Armor_Class` | 防御等级（AC） |
| `Bonus` / `Penalty` | 加值 / **减值** | `HP` | 生命值 |
| `Damage` / `Damage_Type` | 伤害 / 钝击·穿刺·挥砍伤害 | `Energy_Damage` | 火焰·寒冷·电击…伤害 |
| `Attack` / `MeleeAttack` / `RangedAttack` | 攻击 / 近战 / 远程 | `Energy_Resistance` | **抗性**（不是"抗力"） |
| `Dice` | 1d6、2d6… | `Damage_Reduction` | 伤害减免（DR） |
| `Caster_Level` | 施法者等级 | `Spell_Resistance` | 法术抗力 |
| `Combat_Round` / `Check` / `DC` / `Initiative` | 轮 / 检定 / 难度等级 / 先攻 | `Standard_Actions`·`Swift_Action`·`Free_Action`·`Move_Action`·`Full_Round_Action` | 标准·迅捷·自由·移动·整轮动作 |
| `Concealment` | 隐蔽 | `TouchAttack` / `Attack_Of_Opportunity` | 接触攻击 / 借机攻击 |
| `Critical` / `Flanking` | 重击 / 夹击 | `Speed` / `Size` | 移动速度 / 体型 |
| `Healing` | 治疗 | `Alignment` / `Skills` / `Feat` | 阵营 / 技能 / 专长 |
| `Strength`…`Charisma` | 力量…魅力（属性） | `Ability_Scores` / `AbilityDamage` | 属性 / 属性伤害 |
| `Temporary_HP` | 临时生命值 | | |

**常用 `Condition` 键**（官方中文）：`Fatigued`疲劳 · `Sickened`恶心 · `Blind`目盲 · `Paralyzed`麻痹 ·
`Staggered`恍惚 · `Shaken`战栗 · `Stunned`震慑 · `Nauseated`反胃 · `Frightened`惊恐 · `Confusion`困惑 ·
`Exhausted`力竭 · `Prone`俯卧/倒地 · `Entangled`纠缠 · `Daze`眩晕 · `Dazzled`目眩 · `Invisible`隐形 · `Slowed`缓慢 · `Incorporeal`虚体

### 2.2 其它标记

| 标记 | 含义 | 用法 |
|---|---|---|
| `{n}` | **换行** | 官方的分段手段（18515 处） |
| `{mf\|…}` / `{d\|…}` | 性别 / 难度变体 | 一般用不到 |
| `{name}` `{target}` `{source}` `{count}` | 运行时插值 | 一般用不到 |

⚠ **不要自造标记**，不要用 `<b>`、`**`、`-`、`•`。

## 3. 三种文本的差异（抽样结论）

| 文本类型 | 有头区吗 | 正文怎么写 |
|---|---|---|
| **法术**（`AbilityType.Spell`） | 有（学派/环级/施法时间/距离/目标/持续/豁免/抗力） | 1.2 的顺序；术语带链接 |
| **类法术 / 超自然能力**（`SpellLike` / `Supernatural`） | 无学派/环级，但仍渲染施法时间·距离·目标 | 同法术，**但要在正文写清"每天 N 次""如何触发"** |
| **职业特性 / 专长**（`Feature` / `Feat`） | **无头区**（只有名称+图标+正文） | 纯散文；**先写"X 级起"**，再写效果与限制 |

职业特性示例（神恩，全文）：

> 达到2级后，圣武士所有{g|Encyclopedia:Saving_Throw}豁免{/g}均获得等于{g|Encyclopedia:Charisma}魅力{/g}{g|Encyclopedia:Bonus}加值{/g}（若存在）的加值。

专长示例（闪避，全文）：

> {g|Encyclopedia:Armor_Class}防御等级{/g}获得+1闪避{g|Encyclopedia:Bonus}加值{/g}。导致你失去防御等级上的{g|Encyclopedia:Dexterity}敏捷{/g}加值的状态也会使你失去此{g|Encyclopedia:Feat}专长{/g}的效果。

⇒ **特性/专长的正文里连"标准动作""豁免：意志"都不写**，需要时用自然语言（"…时可以…"）。

## 4. 术语与数值规范

| 我们现在写的 | 官方写法 | 说明 |
|---|---|---|
| **罚值** | **减值**（`{g\|Encyclopedia:Penalty}`） | "罚值"不是游戏术语，全库不用 |
| **火焰抗力 / 抗力 10** | **火焰抗性 / 能量抗性 10**（`Energy_Resistance`） | "抗力"只在"法术抗力"（SR）里用 |
| **轰击伤害** | **钝击伤害**（`Damage_Type`） | 官方把 bludgeoning 译作"钝击" |
| **定身** | **麻痹**（`ConditionParalyzed`）/ 束缚 | "定身"不是条件名 |
| **每级** | **每施法者等级**（`Caster_Level`） | 避免与"职业等级"混淆 |
| `+2 洞察加值于 AC` | `AC 获得 +2 洞察加值` | 语序："对象 + 获得 + 数值 + 类型 + 加值" |
| `–1 罚值于其下一次攻击检定` | `攻击检定承受 –1 减值` | 同上 |
| `持续：1 轮` / `持续时间：1 轮` | **不写**（头区渲染） | 正文删除 |
| `20 尺爆发内全部友军` | **不写**（头区渲染 `AoERadius`+目标） | 正文删除 |
| `——克洛丝` / `——种地的大姐姐` | **不写** | 官方正文无作者署名/梗 |
| `（实现为永远落在施法者身后最近空地）` | **不写** | 实现细节不进玩家文本；想留档案就写进 `docs/dev-notes.md` |

**数值写法**：骰子写成 `{g|Encyclopedia:Dice}1d6{/g}`；加值**必须带类型**（士气/洞察/闪避/偏斜/增强/表现/幸运/神圣/不具类型）；
距离用"尺"；动作写"标准动作/迅捷动作…"；豁免写"反射豁免/强韧豁免/意志豁免"（成功/失败的后果用条件从句）。

## 5. 诊断：我们 mod 现在的具体问题（67 条 `spell.*.desc`）

| # | 问题 | 证据 |
|---|---|---|
| 1 | **风格不统一**：27 条带手写状态栏、40 条不带 | `学派：` 出现 27 次 |
| 2 | **状态栏与头区重复**（且会过期） | 例：`学派：预言；距离：60 尺；目标：一名生物；持续：1 轮；豁免：无。` |
| 3 | **0 处术语链接** | `grep "{g\|" LocalizedStrings.json` = 0 |
| 4 | **实现细节泄漏** | `（实现为永远落在施法者身后最近空地）` |
| 5 | **作者署名 / 梗** | `——克洛丝`、`——种地的大姐姐`、`——W` |
| 6 | **术语非官方** | `罚值`、`抗力`、`轰击`、`定身` |
| 7 | **自定义前缀混入正文** | `【恶灵】`、`【10 环】` —— 应改用头区字段（描述符/环级）或删掉 |
| 8 | **句式不统一** | 有的"目标获得 +2 洞察加值于 AC"，有的"攻击 +6（不具类型）" |
| 9 | **状态名不像条件名** | 官方一律用条件词表（战栗/惊恐/麻痹…）；我们用了"沉眠""缓慢"等自造词 |

## 6. 改写模板 + 前后对照（示范 3 条）

**模板**

```
[一句画面/总述。] 主效果：谁 + 获得/受到 + 数值（骰子带链接）+ 类型加值/减值。
[分支：以条件从句收尾，如"成功的 XX 豁免可使此伤害减半。"或"豁免失败者 XX。"]
[例外/限制，另起一段；不叠加、解除条件、适用范围边界。]
```

**对照 A —— 战术标记**

| | 文本 |
|---|---|
| 现在 | `你洞悉目标的步调。你与友军对其进行的下一次攻击检定获得 +1 洞察加值；同一生物同一轮只能受此效果影响一次。` |
| 建议 | `你洞悉目标的步调。你与友军对其进行的下一次{g\|Encyclopedia:Attack}攻击检定{/g}获得+1洞察{g\|Encyclopedia:Bonus}加值{/g}。同一生物同一轮只能受此效果影响一次。` |
| 说明 | 本来就是"只有正文、没有状态栏"的正确形态；只补术语链接与标点习惯 |

**对照 B —— 坚守阵地**

| | 文本 |
|---|---|
| 现在 | `目标获得 +2 洞察加值于 AC，以及 +1 洞察加值于所有豁免检定。以你为中心，30 尺爆发内全部友军，持续 1 分钟/级。——星熊` |
| 建议 | `目标在{g\|Encyclopedia:Armor_Class}防御等级{/g}上获得+2洞察{g\|Encyclopedia:Bonus}加值{/g}，在所有{g\|Encyclopedia:Saving_Throw}豁免检定{/g}上获得+1洞察加值。` |
| 说明 | ① 删掉"以你为中心…持续 1 分钟/级"（头区渲染）；② 删署名；③ 语序改成官方式的"（对象）+ 在…上获得 + 数值 + 类型 + 加值" |

**对照 C —— 紧急撤离**

| | 文本 |
|---|---|
| 现在 | `目标移动至 10 尺内可见的空格（实现为永远落在施法者身后最近空地）。该移动不引发借机攻击，不能穿越实体障碍。` |
| 建议 | `目标移动至 10 尺内一处可见的空格。该移动不引发{g\|Encyclopedia:Attack_Of_Opportunity}借机攻击{/g}，也不能穿越实体障碍。` |
| 说明 | 删掉"（实现为…）"；机制偏差记入 `docs/dev-notes.md` 而不是玩家文案 |

## 7. 落地步骤（建议顺序）

1. **先定"两条铁律"**：① 正文**不写头区字段**；② 所有游戏术语**必带 `{g|}` 链接**。
2. 写一个**校验脚本**（可以照本文的取样脚本改）：
   - 扫描 `LocalizedStrings.json`，报出：正文含 `学派：`/`持续时间：`/`爆发内`/`尺；` 的条目（违规 ①）；
   - 报出含"罚值/抗力/轰击/定身""实现为""——"的条目（术语与非玩家信息）；
   - 统计每条描述里 `{g|` 的个数，0 个的重点复核（违规 ②）。
3. **按批次改写**：先法术（64 条），再特性/能力（集火 / 恶灵 / 灵光 / 圣疗 / 引导 / 源石技艺精通 / 冷静头脑 / 20 级）。
4. **进游戏抽查**：`{g|}` 是否渲染成可点链接、头区字段是否与正文冲突（应无重复）。
5. 把"改过哪些、还差哪些"记进 `docs/dev-notes.md`。

> ⚠ **先验证再批量**：`{g|}` 链接依赖游戏内置百科键，**第一次改完务必进游戏看一条**（例如战术标记）确认链接可点、不报错，再铺开。
