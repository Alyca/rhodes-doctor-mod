## 1. 王冠的回响 `CrownEcho`（10 环 · 特雷西娅）—— 必须由 Macroscope 重写！
- **目标文件**：`src/CrownEchoFx.cs`
- **原作意象**：《明日方舟》特雷西娅（魔王 / 纯黑的王冠），巴别塔与萨卡兹的灵魂领航者，第14章核心主视觉。
- **设计与代码重构要点**：
  1. **彻底摒弃机械蛛网与简单同心圆**：
     不能只是几道平铺直叙的圆环！要有水波荡漾般的交错波纹（如主涟漪、次级微波与外围环相依互推）。
  2. **漫天浮动的粉红微尘与灵魂星芒**：
     微尘不是死板的四边形，要有不同大小、不同漂浮速度与随风摇曳曲线（正弦谐波），颜色要在粉红（`PinkDust`）、玫瑰粉白（`RoseStardust`）与纯净柔白（`SoftWhite`）之间呼吸交融；
  3. **高贵的纯黑之冠**：
     王冠要有优美的弧线起伏与尖冠比例，冠心菱形晶核在空中缓慢沉浮律动；
  4. **敌方增益剥离微尘灵涡**：
     目标身上的微尘环旋转展开并向天空轻柔升腾散逸。
