# 群体法术特效 — 盘点 / 分类 / 素材库 / 进度

> 目标：给 mod 的"群体法术"补齐视觉，做到与官方范围法术一样的观感。
> 原则：从原版借 `PrefabLink`（不写死 AssetId），能带原色就带原色，只在必要时才克隆重染改色
> （改色手法见 `fx-recolor.md`，原版特效一律不碰）。

## 一、素材库（元素化，共 8 个爆发 + 后续 2 个光环）

实现：`src/FxLibrary.cs`（运行时借引用 + 缓存）、`src/FxBorrow.AbilityBurstFx`（从原版法术的
`AbilitySpawnFx` 组件里取爆发 PrefabLink，优先取锚在目标的那一个）。

⚠️ **`AbilitySpawnFx` 是可选组件，很多法术压根没挂**——只按法术借会静默拿不到，表现为法术
完全没特效（大地之怒 / 醉梦最初就是这么丢的）。所以 `FxLibrary.Burst` 现在一律带**区域兜底**：
法术全部落空时退到 `FxBorrow.AreaBurstFx`（区域的一次性爆发动作）→ `FxBorrow.AreaFx`（区域常驻 FX）。

下表"可用"列是**逐个核对原版蓝图字段后的实测结论**（⚠ 标记的是没有 `AbilitySpawnFx` 的）：

挂载机制（按类型四选一，已在 `SpellsSetup.ApplyAbilityFx` 落地 A/B 两类）：

- **A 瞬时点爆发** → 能力 `AbilitySpawnFx`（`anchor: ClickedTarget`, `time: OnApplyEffect`）
- **B 直线** → 直线投射物（按元素分开，见下）/ 落点命中爆发
- **C 持续地面区域** → `area.Fx`（原色）或运行时克隆重染（改色）
- **D/E 群体增益·减益** → 增益 `Buff.FxOnStart` 光环

**尺寸：先看素材的 `Shape`，再决定怎么定大小。**

- **先分清圆/条**：`Shape=Cylinder` 的 `Fx` 才是圆的，且 `Size` 是**半径（尺）**——据此可直接换算缩放
  （半径 5 尺的素材要覆盖半径 10 尺 → `scale=2`），比量包围盒可靠得多。
  `Shape=Wall` 的 `Fx` 是**直线墙，拼不成圆**（刃障 / 锡斯胡德都是这种，剑雨为此白折腾两轮）。
  需要"一圈单个物件"时，借**投射物外观**（`FxBorrow.ProjectileViewFx`）自己按个数摆。
- **别用包围盒反推尺寸**：粒子系统的 `bounds` 会被吹得远大于可见粒子（实测刃障报 348 米，
  画面上只有约 25 米）。所以 `FitToMeters`（按包围盒自适应）**只适合网格 / 贴地类素材**；
  粒子含量高的必须用固定 `Scale` 并按**画面实测**反推。

首次生成时会打一条 `[RhodesDoctor][特效尺寸]` 日志，含**缩放前**的总尺寸和**每个渲染器的明细**
（粒子/网格、各自尺寸、粒子的 `startSize`）。拿它对比"画面上实际多大"，就能判断包围盒有没有被吹大。

**改色（个别法术要非原色时）**：`FxTint`（通用"克隆 + 重染"，`SmokeFx` 已改用它）
+ `ContextActionSpawnTintedFx`（挂在 `AdditionalAbilityEffectRunOnClickedTarget` 上，
每次施放在落点生成一份重染克隆，销毁后自清）。首个用例：**剑雨 → 剑阵（刃障）重染橙金**（见下）。

**直线投射物（按元素）**：灼烧 → `FireLine00`；耀阳颔首 → `SearingLight00`；
穿云 → `Sithhud_SwordTraceLine00`；王者冲锋 → `Kinetic_EarthBlastLine00`；其余默认闪电束。
（灼烧只保留火焰直线，**不再叠落点爆发**——原先的落点爆发受击时太华丽。）

## 三、批次进度

- **第一批（A+B，12 个）**：接线见 `SpellsSetup.ApplyAbilityFx`。
  剑雨 / 火山 / 闪光弹 / 醉梦 / 黄昏 / 雷霆审判 / 大地之怒 / 炮火延伸（A）
  + 灼烧 / 王者冲锋 / 耀阳颔首 / 穿云（B）。
  - ⚠️ **勘误（2026-10-08 复核）**：这批原来标"已完成"，但**运行时只有 3 个元素借到了素材**
    （火=焰击术、电=召雷术、光=阳炎爆）。物理（落石/黑曜流）与精神（心灵迷雾）的候选
    **都没有 `AbilitySpawnFx`**，`FxBorrow` 静默跳过，所以**大地之怒、醉梦当时完全没有特效**，
    王者冲锋 / 穿云的落点爆发也缺失（这两者还剩直线投射物，所以看不太出来）。
    已按 `FxLibrary` 的元素表修正 + 加区域兜底，现物理/精神必定能借到。
  - ✅ **剑雨已定案（2026-10-09，共九版）**：真正的死结是——刃障 `BladeBarrierArea`（`Shape=Wall,
    Size=60`）和锡斯胡德 `DLC5_SwordOfSithhudAreaEffect`（`Wall, Size=180`）**都是直线墙**，原版
    **没有"圆形剑阵"的地面 FX**，所以"复制 12 份拼圆"和"1 份缩小"出来的都还是**一条**。
    最终版：**借原版武器模型（巨剑网格，`FxBorrow.WeaponModelFx`）摆同心双环、从天而降**，光尾**自绘**
    （不再借粒子素材）。定案参数：`Count=18, Rings=2, Radius=2.4 m（内环 1.2）, RadiusJitter=0,
    TiltJitter=0, YawJitter=0, ScaleJitter=0, OffsetUp=1.2 m, OffsetUpJitter=0, Pitch=180,
    FitLongestMeters=1.5 m`（⚠️ 竖直物件必须用"最长边"，`FitToMeters` 只量到剑身厚度、整把剑会被放大
    好几倍）、`FallFromMeters=9, FallSeconds=0.4, FallSecondsJitter=0, Lifetime=2`、
    `GoldenStreak=true, StreakSeconds=0.25, StreakWidth=0.15 m`；另加**逐目标命中金光**
    （`ContextActionSwordHitFx`，`Delay=0.4` 跟落剑同步）。
    ⚠️ 旧版的"圆盘内随机散布 + 横七竖八 + 借粒子拖尾 + 16 m/1.1 s"**已被用户否掉**，
    完整经验与"别再改回去"清单见 `dev-notes.md` §7。
    借不到武器模型时兜底用一个**圆形**地面符文（半径 5 尺的 `RuneDomainBaseAbilityFireArea`，`scale=2` → 半径 10 尺）。
- **C 类已开工（2026-10-09）**：✅ **钙质化**（20 尺区域）——`area.Fx` 借原版土系持续区域
  （`FxLibrary.CalcificationGround`，首选 `DeadlyEarthEarthBlastArea`，`Cylinder/Size=20` 与法术半径相等、
  **不用缩放**），**原色**挂载、引擎管生命周期。这是 C 类的**首个样板**，选材法见 `fx-status.md` 第二节的 ✅ 注。
  **C 类选材三条（离线查 `blueprints.zip`，别进游戏试）**：① `Shape` 必须 `Cylinder`（`Wall` 是直线墙，拼不成圆）；
  ② `Size` 与法术半径相等就免缩放（`Cylinder` 的 `Size` 是**半径（尺）**）；③ `Fx` 非 null。
